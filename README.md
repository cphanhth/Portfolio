# Christian Phanhthourath Portfolio

This is a personal portfolio website built with **React.js**, **HTML**, and **CSS**. It showcases my education, work experience, projects, skills, and more. The website is designed to be easily accessible and responsive, ensuring a smooth user experience across devices.

## Features
- A clean and modern design to highlight achievements.
- Sections for Education, Work Experience, Projects, Skills, and Contact Information.
- Linked social media accounts and an email for easy communication.

## Technologies Used
- **React.js**: A JavaScript library for building user interfaces.
- **HTML5 & CSS3**: For the structure and styling of the website.
- **Node.js**: For running the application locally.
